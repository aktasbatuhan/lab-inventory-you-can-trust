Assume the expected thing happened, and make the exception loud

The common case should cost nobody anything. Doing something different has to be reported, so it can’t slip by.

Single-use plates

recorded as thrown away when their run finishes, by rule. If one is scanned later, that’s a flag.

A robot run that finished

did its worklist. A missing log line becomes an assumed step, flagged, and the real line replaces it if it turns up.

A robot run that aborted

assumes nothing. Both ends of every missing step are flagged until a person says what happened.
