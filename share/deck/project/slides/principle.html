So every number can show how it was worked out, fixing one fact fixes everything that depends on it, and what can’t be worked out says “unknown, because…” instead of guessing.

This is the principle everything else follows, and I set it before anything else: every value has to be computable. The database stores two kinds of thing: facts, meaning something happened at a time and someone recorded it, and rules, like how long loading buffer lasts. Amounts, locations, expiry dates, thaw counts and usability are all worked out when someone asks.
