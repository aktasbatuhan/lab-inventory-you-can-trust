How we worked: break it, then fix it on purpose

Every stage tried to prove the design wrong in a different way. Agents found problems but weren’t allowed to fix the schema; each fix became a written decision and a test.

Scenarios

244 stories from six agents, real error rates, Codex as the adversary

Schema

Facts, rules and two times on everything

Tests

21 stories as code. Caught: “a month in the fridge” was ambiguous

Demo answers

Read like a scientist would. Caught: a lost robot log line

Dice lab

Weeks of lab at scale. Caught: a 77-second query, ghost bins

Agent lab

AI staff under time pressure. Caught: two vials on one slip

This is the slide about how I worked, and it matters more than any single result. Each stage was built to find what the previous one missed. The tests caught logic gaps. Reading real answers from a demo lab caught things no test asked about. The dice simulation found problems that only show up at scale, including a query that took 77 seconds. The agent lab found things nobody had written down as a scenario, like a packing slip with two vials. Agents could report but never patch the schema, so every fix was a decision made on purpose. Everything went back into the design: 11 decisions written down with their reasons, each one covered by a test, and every agent's raw write-up kept in the repo's journal.
