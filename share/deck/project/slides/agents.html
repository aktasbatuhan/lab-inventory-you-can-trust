The agent lab: AI staff, a clock and a referee

Dice only make the mistakes we thought of. So four AI agents played Adaptyv’s lab staff for a week, roles taken from Adaptyv’s job posts, and nobody told them to make mistakes.

Hands

Tools that change the real lab: pick up, pipette, split, bin. Labels frost, vials come short.

A pen

Separate tools that write to the inventory, true or not. Mistakes appear on their own.

A clock

A scan costs 10 seconds, a record 30. Deadlines, interruptions, shifts end at 18:00.

A referee

Codex reads both notebooks each evening and writes up new scenarios.

What nobody planted

Lena couldn’t book the second vial on a two-vial packing slip. Usable PD-L1 read 963 µL against a true 1,150. Delivery references are now per vial.

Answers that misled them

Asking for a freezer by name returned nothing, read as empty. Procurement asked four days running how fast target is used. Both are fixed, and the rate is now a query.

The people are headless Claude Code sessions, the referee is Codex, and both ran on my own subscriptions, not API credits. Each person keeps one session for the whole week, so they remember yesterday. The agents never get SQL or a shell, only the lab's tools, so they meet the inventory the way people would. The packing slip is the kind of thing I wanted this for: none of the 244 scenarios had it, and it's exactly the brief's "material we own looks used up". Over the full week, four people on Sonnet took 697 actions, the referee wrote up 23 scenarios (one new, nineteen variants of ones we had), and final usable target was 1,893 µL on record against 1,895 really there. The most useful findings weren't wrong numbers but answers that misled people: an empty result that read as "empty freezer", and a question the inventory couldn't answer at all.
